# Old Frugal Mechanic Repositories

FrugalMechanic was a comparison shopping site for automotive parts that operated from 2008 to ~2019. It was run by ([@tpunder](https://github.com/tpunder)) and ([@er1c](https://github.com/er1c)). **The domain expired and was taken over by a spammer so I won't reference it here.**

Here are some examples of what it looked like originally via the [Internet Archive](https://web.archive.org/):

- [Home](https://web.archive.org/web/20160711062913/http://frugalmechanic.com/)
- [Browse](https://web.archive.org/web/20160505022251/http://frugalmechanic.com/auto-parts)
- [Detail](https://web.archive.org/web/20150414130402/http://frugalmechanic.com/auto-part/centric-12640021sl-brake-disc)
- [Coupons](https://web.archive.org/web/20160503175052/http://frugalmechanic.com/coupons)
- [About](https://web.archive.org/web/20160504122117/http://frugalmechanic.com/about)
- [Blog](https://web.archive.org/web/20160508002718/http://frugalmechanic.com/blog)
